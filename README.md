Nombre del proyecto: Reserva de asientos de una sala de cine
--------------------
Objetivo del programa
----------------------
Desarrollar un programa en Python que permita gestionar la reserva de asientos de una sala de cine de 3 × 4, utilizando listas anidadas, índices y bucles anidados para representar y recorrer la matriz de asientos.

como ejecutar el programa:
---------------------------
Abrir el programa reserva_cine.py. Luego ingresar la fila y columna del asiento que se desea reservar. El programa mostrará el estado completo de la sala utilizando 0 para asientos libres y 1 para asientos reservados.
